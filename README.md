
# APT Dependency Graph Visualizer

Практическая работа №2.
Дисциплина: Конфигурационное управление.
Вариант №1.

## Описание

Консольная программа на Python для анализа
и визуализации зависимостей пакетов Ubuntu APT.

## Функции и настройки

Программа считывает TOML-конфигурацию, проверяет
значения всех шести параметров и выводит их на экран.

Параметры config.toml:

- package_name — имя анализируемого пакета.
- repository — URL репозитория или путь к тестовому файлу.
- test_mode — режим тестового репозитория.
- output_file — имя выходного SVG-файла.
- ascii_tree — режим вывода ASCII-дерева.
- exclude_substring — подстрока для исключения пакетов.

## Запуск программы

    run.bat

Или:

    py -m src.main

## Запуск тестов

    py -m unittest discover -s tests -v

## Пример использования

При запуске программа выводит значения всех шести
параметров из файла config.toml.

При некорректных настройках выводится сообщение
Configuration error с описанием ошибки.
