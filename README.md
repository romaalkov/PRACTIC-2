
# APT Dependency Graph Visualizer

Практическая работа №2.
Дисциплина: Конфигурационное управление.
Вариант №1.

## Описание

Консольная программа на Python для анализа
и визуализации зависимостей пакетов Ubuntu APT.

## Реализованные функции

Этап 1:
- Чтение конфигурации из TOML.
- Проверка шести параметров.
- Обработка ошибок конфигурации.

Этап 2:
- Скачивание индекса Packages.gz по URL.
- Чтение записей пакетов Ubuntu.
- Получение Depends и Pre-Depends.
- Вывод прямых зависимостей.
- Обработка ошибок получения данных.

В следующих этапах будут реализованы
BFS, обратные зависимости и PlantUML.

## Настройки config.toml

- package_name — имя пакета.
- repository — URL репозитория.
- test_mode — тестовый режим (появится на этапе 3).
- output_file — имя SVG-файла.
- ascii_tree — вывод ASCII-дерева (этап 5).
- exclude_substring — фильтр пакетов (этап 3).

## Запуск программы

Windows:

    run.bat

Или:

    py -m src.main

## Запуск тестов

    py -m unittest discover -s tests -v

## Пример использования

В config.toml указать:

    package_name = "bash"

Запустить программу:

    run.bat

Программа выводит прямые зависимости пакета bash.

Альтернативные зависимости отображаются через |.
Ограничения версий пока не выводятся.

## Этап 3. Построение графа зависимостей

Реализован алгоритм BFS без рекурсии.

Возможности:
- Поиск прямых и транзитивных зависимостей.
- Обработка циклических зависимостей.
- Исключение пакетов по заданной подстроке.
- Работа с настоящим репозиторием Ubuntu.
- Тестовый режим с пакетами A, B, C и т. д.

### Формат тестовых данных

Каждая строка содержит пакет и его зависимости:

    A: B, C
    B: D
    C: D
    D:

Пакеты должны иметь имена из заглавных
латинских букв.

### Тестирование

    py -m unittest discover -s tests -v

Для проверки различных ситуаций используются
файлы в tests/data/.

### Ограничения

Альтернативы пакетов рассматриваются как
возможные связи графа.

Разрешение виртуальных пакетов и ограничений
версий пока не реализовано.

Граф выводится в консоль как список связей.
Визуализация PlantUML и SVG будет добавлена
на этапе 5.


## Этап 4. Обратные зависимости

Реализован поиск обратных зависимостей пакета.

Обратные зависимости — это пакеты, которые
прямо или транзитивно зависят от выбранного пакета.

Для поиска используется алгоритм BFS без рекурсии.

Программа обращает направления рёбер исходного
графа и выполняет обход из выбранной вершины.

Поддерживаются:
- Прямые и транзитивные обратные зависимости.
- Циклические зависимости.
- Фильтрация пакетов по подстроке.
- Работа с тестовыми файлами.
- Работа с индексом Ubuntu APT.

### Пример

Тестовый граф:

    A: B, C
    B: D
    C: D
    D:

Для пакета D обратные зависимости:

    B, C, A

### Запуск

    run.bat

### Тестирование

    py -m unittest discover -s tests -v

## Этап 5. Визуализация зависимостей

Реализована визуализация графа зависимостей
на языке PlantUML.

Возможности:
- Построение графа зависимостей алгоритмом BFS.
- Генерация текстового описания PlantUML (.puml).
- Сохранение изображения в SVG.
- Вывод ASCII-дерева при ascii_tree = true.
- Обработка повторяющихся и циклических связей.

### Запуск

    run.bat

Для генерации SVG используется онлайн-сервер
PlantUML. Требуется подключение к интернету.

В config.toml указывается анализируемый пакет
и имя выходного SVG-файла.

### Демонстрационные пакеты

- bash
- nano
- grep

### Тестирование

    py -m unittest discover -s tests -v

### Сравнение с APT

Для сравнения используются команды:

    apt-cache depends ИМЯ_ПАКЕТА
    apt-rdepends ИМЯ_ПАКЕТА

Возможные расхождения связаны с ограниченным
индексом пакетов, альтернативными зависимостями,
виртуальными пакетами и учётом версий.
