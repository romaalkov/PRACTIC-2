
# APT Dependency Graph Visualizer

Практическая работа №2.
Дисциплина: Конфигурационное управление.
Вариант №1.

## Описание

Консольная программа на Python для анализа
и визуализации зависимостей пакетов Ubuntu APT.

## Реализованные функции

Этап 1:
- Чтение конфигурации из TOML.
- Проверка шести параметров.
- Обработка ошибок конфигурации.

Этап 2:
- Скачивание индекса Packages.gz по URL.
- Чтение записей пакетов Ubuntu.
- Получение Depends и Pre-Depends.
- Вывод прямых зависимостей.
- Обработка ошибок получения данных.

В следующих этапах будут реализованы
BFS, обратные зависимости и PlantUML.

## Настройки config.toml

- package_name — имя пакета.
- repository — URL репозитория.
- test_mode — тестовый режим (появится на этапе 3).
- output_file — имя SVG-файла.
- ascii_tree — вывод ASCII-дерева (этап 5).
- exclude_substring — фильтр пакетов (этап 3).

## Запуск программы

Windows:

    run.bat

Или:

    py -m src.main

## Запуск тестов

    py -m unittest discover -s tests -v

## Пример использования

В config.toml указать:

    package_name = "bash"

Запустить программу:

    run.bat

Программа выводит прямые зависимости пакета bash.

Альтернативные зависимости отображаются через |.
Ограничения версий пока не выводятся.
