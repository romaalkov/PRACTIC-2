
# APT Dependency Graph Visualizer

Практическая работа №2.
Дисциплина: Конфигурационное управление.
Вариант №1.

## Описание

Консольная программа на Python для анализа
и визуализации зависимостей пакетов Ubuntu APT.

## Функции и настройки

На начальном этапе программа выводит
приветственное сообщение.

В следующих этапах будут реализованы
конфигурация TOML, получение зависимостей,
обход графа BFS и визуализация PlantUML.

## Запуск программы

Windows:

    run.bat

## Запуск тестов

    py -m unittest discover -s tests -v

## Пример использования

    py -m src.main
